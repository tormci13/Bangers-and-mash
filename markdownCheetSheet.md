```

```
---

## 3. Lists
### Unordered Lists
```markdown
- First item
- Second item
  - Indented sub-item (use 2 or 4 spaces)
- Third item
```

### Ordered Lists
```markdown
1. First item
2. Second item
3. Third item
```

### Task Lists
```markdown
- [x] Completed task
- [ ] Incomplete task
```
